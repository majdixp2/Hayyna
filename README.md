# Arabica Pathfinder ☕🍽️
### منصة عروض وتخفيضات المطاعم والكافيهات بالخريطة التفاعلية

تطبيق أندرويد متكامل مبني باستخدام **Kotlin** و **Jetpack Compose** و **Material 3**، مستوحى من فكرة Arabica Pathfinder ولكن بإمكانيات ومميزات احترافية متقدمة.

---

## 🌟 المميزات الرئيسية (Key Features)

### 1. 🗺️ خريطة العروض التفاعلية (Interactive Map)
- استعراض مواقع المطاعم والكافيهات على خريطة تفاعلية بالرياض ومناطق المملكة.
- مؤشرات بصرية ديناميكية تدل على نوع العرض، الخصم، ونوع الميديا (صور وفيديو).
- شريط سفلي متطور (Bottom Carousel) لاكتشاف العروض الأقرب إليك فورياً مع حساب المسافة ووقت القيادة.

### 2. 🏷️ صفحة العروض للعملاء (Customer Offers Explorer)
- تصفح شامل لقائمة العروض والخصومات النشطة دون الحاجة للبحث بالخريطة.
- **عرض دقيق للمسافات:** بطاقة كل مطعم توضح بدقة المسافة الفاصلة (مثلاً: `يبعد 850 م` أو `يبعد 2.4 كم`) مع زمن الوصول التقديري بالسيارة.
- فلاتر متقدمة: حسب المنطقة والحي، نوع المطبخ (برجر، قهوة مختصة، شاورما، حلويات، مشويات، بيتزا)، وفلتر خاص بالفيديوهات الترويجية.
- خيارات ترتيب ذكية: حسب الأقرب مسافة، الأعلى تقييماً، الأقل سعراً، أو نسبة الخصم الأعلى.
- زر مباشر "عرض على الخريطة" للتوجه مباشرة لموقع العرض على الخريطة.

### 3. 🏪 بوابة التاجر المستقلة (Merchant Portal)
- تسجيل دخول مخصص لأصحاب المطاعم والمتاجر عبر البريد الإلكتروني.
- لوحة تحكم التاجر مع إحصائيات حية: عدد العروض النشطة، المشاهدات، طلبات التوجيه للمحل، والتقييم.
- نقل زر **"إضافة عرض جديد"** لبوابة التاجر الخاصة لمنع عبث الزوار.
- إمكانية إضافة عروض جديدة مع تفاصيل الأسعار، نسبة الخصم، نوع الميديا (صورة أو فيديو)، الموقع، والحي.

### 4. 🛡️ لوحة إدارة النظام (Admin Portal)
- مراجعة واعتماد أو رفض العروض المدخلة.
- تمييز العروض الأكثر رواجاً (Featured Offers).
- إحصائيات شاملة لإجمالي المتاجر والعروض في المنصة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Language:** Kotlin 100%
- **UI Toolkit:** Jetpack Compose (Material 3)
- **Architecture:** MVVM + Clean Architecture with Coroutines & StateFlow
- **Responsive Design:** دعم كامل للشاشات المتكيفة (Edge-to-Edge) والوضع المظلم/الفاتح
- **Testing:** Robolectric JVM Tests

---

## 🚀 كيفية فتح وتشغيل المشروع (How to Run)

1. افتح **Android Studio** (نسخة Ladybug أو أحدث).
2. اختر **Open** وحدد المجلد الخاص بالمشروع.
3. انتظر انتهاء مزامنة **Gradle Sync**.
4. اختر المحاكي أو جهاز حقيقي واضغط **Run (Shift + F10)**.
